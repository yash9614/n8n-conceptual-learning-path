# 09 - Templates Gallery

This folder contains the original "100+ Plug-and-Play n8n Templates" collection, lightly cleaned and categorized where possible.

## How to Use

1. Browse by filename or category below
2. Import the JSON into your n8n instance
3. Configure credentials
4. Study the node structure and sticky notes
5. Modify and adapt to your needs

## Categories (Approximate)
